# Salt-Econ-Tools

A collection of economic modeling tools and simulations focusing on Austrian economics principles and cryptocurrency mining profitability analysis.

## Project Overview

This repository contains two main components:

1. **Austrian Economics Models** - A framework for simulating economic principles based on Austrian economic theory, including:
   - Agent-based modeling
   - Market simulation
   - Economic system visualization

2. **Bitcoin Mining Profit Model** - A Python program to analyze and predict profitability of Bitcoin mining operations based on various parameters.

## Installation

```bash
# Clone the repository
git clone https://github.com/Salt-555/Salt-Econ-Tools.git

# Navigate to the project directory
cd Salt-Econ-Tools

# Install dependencies (if requirements.txt is added in the future)
# pip install -r requirements.txt
```

## Usage

### Austrian Economics Models

```python
# Run the main simulation
python -m austrian_economics_models

# Or import specific components
from austrian_economics_models.core import agents, market, economy
from austrian_economics_models.visualization import gui, plots
```

### Bitcoin Mining Profit Model

```python
# Run the BTC mining profit model
python "BTC mining profit model python program.py"
```
